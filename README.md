# find-difference-game
DxLibで制作した間違い探しゲームです。

ゲーム概要
画像の中に間違いをクリックして探すゲームです。
クリアタイムと正答率で他者と競えます。

制作意図
unityで作成し、unityゲームジャムに投稿した物をベースにプログラミングやゲームエンジンを理解するためにDxlibで再実装しました。
unityのボタンの楽さとDxLibで作るクリック判定の大変さがわかりました。

工夫した点
ランダム配置にすることで毎回結果が変わるように
場合によってはもうひとつが見えずらかったので一定時間でヒントを出すように
入力処理ではクリック判定の処理部分を二つにしてたのですが安定しなかったので処理を一つにしました。
